# duoscribe

Write raw markdown. See it rendered. Same window, same moment.

A small, fast, free markdown editor for macOS and Windows. No account, no sync, no bloat — just .md in, formatted text out, side by side.

try-it.md

↑ edit the raw text, drag the divider — this is the actual interaction model of the app

-- what's in it

Everything a markdown file needs, nothing it doesn't

⇔

Resizable split

Drag the divider to any ratio you like. Double-click to snap back to 50/50.

#

Folder sidebar

Open a folder and browse its markdown files in a collapsible tree, without leaving the app.

⇥

Multi-file tabs

Keep several documents open at once and switch between them like a code editor.

⌕

Find & replace

Jump between matches with a live counter, or replace one occurrence — or all of them.

↕

Synced scrolling

Scroll either pane and the other follows proportionally, so you never lose your place.

↻

Auto-reload

Edit the file in another tool and Duoscribe picks up the change automatically.

↓

Drag & drop

Drop one or several .md files straight onto the window to open them.

↗

Export & associate

Export the rendered view, and open .md/.markdown files straight from Finder or Explorer.

macOS · Intel

x64 Download .dmg

Windows

x64 / arm64 Download .exe

These builds aren't code-signed yet, so your OS will flag them on first launch. Apple Silicon: macOS will say the app "is damaged" — it isn't; run xattr -cr /Applications/Duoscribe.app in Terminal, then open it normally. Intel: right-click the app → Open. Windows: click More info → Run anyway. Details in the README.
